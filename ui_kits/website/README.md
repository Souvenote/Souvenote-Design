# Souvenote — Website UI Kit

A pixel-faithful recreation of the Souvenote marketing site, split into reusable React components. Built to demonstrate the dark editorial chrome, the animated gold / silver / rose-gold gradients the user requested, and the full hero interactions, including the music playback, card flip, and gallery swipe.

Contents:
- `index.html` & `index-loggedin.html` & `index-print.html` — three variants of the same screen
- `Navbar.jsx`, `Hero.jsx`, `Gallery.jsx`, `FAQ.jsx`, `Footer.jsx`, `HowItWorks.jsx`, `Ornaments.jsx` — React components
- `site.css` — component styles
